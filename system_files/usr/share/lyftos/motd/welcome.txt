# Welcome to lyftOS

Built on Bazzite and Universal Blue.

## Deployment status

```text
${MOTD_DEPLOYMENT}
```

| Command | Description |
| ------- | ----------- |
| `bootc status` | Inspect booted, staged, and rollback deployments |
| `ujust --choose` | Browse inherited Bazzite setup tools |
| `ujust toggle-user-motd` | Toggle this banner on/off |
| `brew help` | Manage command line packages |

Recovery: check the rollback deployment with `bootc status`, then use
`sudo bootc rollback` and reboot. This restores the OS, not your home directory
or applications stored outside the image. The previous deployment may be
Bazzite if you have only just switched to lyftOS.
